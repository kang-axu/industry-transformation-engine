# ITE Cases

This directory is reserved for real industry-transformation cases.

A case should document:

- industry and business context
- original workflow
- initial assumptions
- giant/reference study
- calibration evidence
- system design
- human-AI role split
- deployment
- real-world outcomes
- failures
- FTD links
- reusable assets created
- what became standard
- what remained industry-specific
- what remained client-specific

## Candidate first case

A future **CASE-001** should be added only after a real transformation has enough evidence to support a meaningful case study.

No fabricated success cases.
